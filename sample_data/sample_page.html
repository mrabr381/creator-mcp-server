Second Heading That Should Not Exist

This is a deliberately thin sample page built to test the single page SEO audit tool. It contains just enough words to sit between one hundred and three hundred visible words, so the word count check should score a half mark rather than a full pass or a complete fail. The page also carries a canonical link and an Open Graph title, but it is missing a meta description entirely and its title tag runs far too long for search results. Two heading one tags compete for the main heading, and one of the two images below has no alternative text at all, which hurts both accessibility and image search. The structured data is the one thing done right, with a small frequently asked questions block that search engines and AI answers can cite directly.
